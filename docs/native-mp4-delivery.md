# Provider-approved native MP4 delivery

The optional rights.nativeMp4 flag declares that the provider authorizes native HTML5 MP4 delivery, including an opaque HTTPS endpoint without a filename extension. Synchronized providers must also explicitly enable allowNativeMp4 and provide independently measured evidence for the exact URL, actual MP4 container, native playback delivery, and Cinema origin. This is an authorized delivery mode only; no extraction, credential forwarding, proxy, header spoofing, or access-control bypass. HLS retains the normal CORS mode. No AlooYTV source, domains or media URLs are configured. Synthetic browser fixtures demonstrate playback without CORS using an opaque URL and normal fallback. A provider grant must be independently reviewed before enabling any source.
