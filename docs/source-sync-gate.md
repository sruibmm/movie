# Source synchronization gate (staging)

No AlooYTV adapter, scraper, playback URLs, account, or production deployment is included. The existing licensed HLS/MP4 path remains unchanged. The gate accepts only an explicitly reviewed provider grant, allowlisted HTTPS media hosts, complete declared seasons, current rights for Kuwait, and recent playback observations of at least 720p. The observation must come from an independent authorized playback test, not the feed itself. Synthetic fixtures establish validation logic, not actual availability or rights. No secret URLs in public snapshots. A new title batch requires 50 titles; maintenance of existing titles can update URLs without changing IDs. Rejected snapshots keep the previous catalogue; playback rights must still be checked at use time. Explicit withdrawals need a separately reviewed process; do not serve expired rights. Persistent storage, scheduling, trusted observation generation, and provider authorization are prerequisites before production. Run: node scripts/source-sync-gate-test.mjs.
