# Cinema Direct synchronized playback (staging only)

The native Cinema Player now accepts a canonical work/season/episode reference from a server-side reviewed catalogue. The catalogue endpoint contains metadata only. Resolve returns authorized, current candidates sorted by measured resolution. Fatal errors or a playback timeout cause a single retry of each matching candidate, retaining the current time; no iframe, redirect or unrelated source is used. The staged worker combines the existing app and synchronization routes on one origin. Source policies remain empty until an authorized provider supplies a catalog and independently measured playback observations. This is not AlooYTV playback or authorization. No AlooYTV media, URL extraction, scraping or reverse proxy is included. The source-sync staging configuration is separate from production; cron and Durable Object only activate on deployment. Legacy Cinema paths remain unchanged. Browser-specific playback and coupled synchronization require real device testing.
