# Isolated scheduled source synchronization worker

This is an implementation in staging, not a deployment or an AlooYTV integration. Use a separate worker name and config: wrangler.source-sync.jsonc. It schedules a sync every six hours, uses a SQLite Durable Object to persist each approved provider's last valid snapshot, atomically replaces it only after validation, and exposes status and exact canonical work/season/episode candidate resolution. The browser can exclude a failed candidate and retry another; this is a resolver, not yet wired into the production React player. Provider configuration defaults to an empty list. No provider endpoints, media, accounts, or authorization are assumed. Configure independently authorized feed and observation JSON URLs on allowlisted hosts, provider grant, and a manually reviewed canonical work crosswalk. Observations are trusted inputs from an independent playback review; they are not measured by this worker. Expired observations and rights are excluded at lookup. The six-hour cron only becomes active on deployment. A separate real-source smoke test and authorization are required before production. Tests use synthetic fixtures and an in-memory storage implementation; Cloudflare deployment and actual browser playback remain untested.
